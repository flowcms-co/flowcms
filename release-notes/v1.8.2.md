# v1.8.2: lint cleanup, no visible changes

A maintenance release. Nothing changes in how the studio or the API
behave, so there is nothing to do after updating.

## Code checks now run on every change

The studio's code checker reported 43 problems, 3 of them errors, that
had built up over several releases. The API's checker had never been
set up, so it failed before checking anything. Both are now clean, and
both run automatically on every change, where any new problem fails the
build instead of piling up.

## What was cleaned up

- The Topic Clusters page rebuilt its filtered and sorted lists on
  every render. They are now reused until the underlying data changes.
- Removed code that was never used: a few imports, two helper
  functions, a loading flag nothing read, and a block of sample data.
- Removed suppression comments that no longer did anything, and gave
  the remaining ones a written reason.
- The live-edit script served to customer sites is no longer checked
  with rules meant for the studio's own code. The script itself is
  unchanged.

## Notes

No migrations, no config changes, no new environment variables. API
and studio.
