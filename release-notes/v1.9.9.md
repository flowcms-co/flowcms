# v1.9.9: Node.js security update and a new license signing key

## Node.js 22.23.4

The Docker images now run Node.js 22.23.4. Earlier 22.x releases carry a
critical remote code execution vulnerability (Node.js security release,
October 2026), so every self-hosted install should update.

- The base image is pinned to `node:22.23.4-bookworm-slim` instead of the
  floating `node:22` tag, so a cached older layer can no longer slip into a
  build.
- CI runs on the same version.

## New license signing key

Following the October 2026 incident at our hosting provider, licenses are now
signed with a new key, and this release ships its public half.

- Paid installs with telemetry on renew onto the new key on their next
  heartbeat. Nothing to do.
- Licenses signed with the old key keep working on this release until
  January 31, 2027. If you added a license by hand, or run with
  `FLOWCMS_TELEMETRY=off`, ask us for a re-issued key before then.
- Installs that pin `LICENSE_PUBLIC_KEY` trust only that key, as before.

No database migrations. Pull the new image and restart.
