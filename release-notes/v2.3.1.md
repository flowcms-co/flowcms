## Highlights

Elements for any service: the cost estimator and a new custom calculator now fit any trade (pest control, roofing, electrical and more), the theme sets text size per device, and editors get page Undo, Redo and Discard changes.

## What's new

- Cost Estimator: neutral starting values and an optional price unit, such as "per visit" or "per roof square", shown after the range.
- Calculator: a new Custom preset where you set everything: the quantity label, the option picker label, up to four named rates, the low and high range, the result caption and a note. Drying cost and insurance out of pocket work exactly as before.
- Element theme text size: Auto (one size that steps down in narrow spaces) or set per device (phone, tablet, desktop). Sizes follow the width of the space the element sits in, so an element in a narrow column uses the phone size.
- Editor: Undo and Redo for the whole page in the top bar, with Cmd/Ctrl+Z and Shift+Cmd/Ctrl+Z outside text boxes. Up to 50 steps per editing session.
- Editor: "Discard changes" puts a published page's draft back to what is live. The discarded draft stays in version history.

## Fixes and improvements

- Edit theme now opens with the theme you saved, not the default.
- Reference lists (such as Cities and Tags) keep their page, filters, sort and tab when you open an entry and go back.
- General stability and performance improvements.
