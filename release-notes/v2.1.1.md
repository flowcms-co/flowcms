# v2.1.1: security fixes

A security release. Upgrade soon. Nothing to configure: two small migrations run on
boot, and existing settings keep working.

## Fixed

- **Uploads can no longer run as pages or scripts.** A file's stored extension now
  comes from its checked type, never from the uploaded file name. Files under
  `/media` that aren't images, video, audio or PDF are served as downloads in a
  sandbox, and every media file is sent with `nosniff`.
- **Rate limits can't be dodged.** Limits are keyed by the signed-in user or the
  client IP, never by an unchecked token or cookie.
- **Sign-in lockout.** Ten failed sign-ins or 2FA codes in a row lock the account
  for 15 minutes, with the same message whether or not the email exists. A 2FA code
  works only once.
- **Stronger password hashing.** Passwords are upgraded automatically the next
  time each person signs in.
- **Sessions end when they should.** Deactivating a user signs them out
  everywhere, and changing your password signs out your other devices.
- **No more role escalation.** Only a Super Admin can grant or remove Super Admin
  or the all-permissions role, and roles accept only known permissions.
- **Preview is sanitized.** Entry HTML is cleaned before Studio previews render it.
- **Storage and SMTP settings refuse private addresses.** Saving an endpoint or
  host that points at a private, loopback or cloud metadata address is refused.
  Running MinIO or a mail relay on your own private network? Set
  `ALLOW_PRIVATE_FETCH=true` (optional, only needed when you save those settings).
- **Studio sends security headers** (HSTS, frame protection, nosniff, referrer and
  permissions policies) on every page.
- **Dependencies updated** with their security fixes, including Next.js 16.4.3,
  nodemailer 10, sharp 0.35 and multer 2.5. Base images are pinned.
- Forgot-password log lines no longer show the full email address.

## Small changes you might notice

- Public delivery requests made with an API token are rate limited per client IP.
- The license heartbeat now carries a per-install key issued by the license
  server, stored encrypted.
