## Highlights

Elements (Enterprise, `elements`): drop a ready-made cost estimator, table, steps infographic or calculator into any rich text field, between any two blocks, and it is delivered as finished HTML your site can show as is.

## What's new

- Elements are an Enterprise feature, unlocked by the `elements` entitlement in the license. Without it the Insert element menu is hidden, and elements already on a page still show, so a lapsed license never breaks a live page.
- Four templates: Cost Estimator (low, average and high with an optional source note), Table, Steps Infographic (3 to 6 steps, horizontal or vertical) and Calculator (drying cost or insurance out of pocket).
- Insert element: in any rich text field, after a heading, a paragraph or a list. Each element keeps its own values in that page, and you edit it in a side drawer.
- Elements are checked only when they are used: a cost estimator needs low, average and high in order, steps need 3 to 6 filled steps, and a table needs a header and two rows. A broken element cannot be published.
- Public delivery turns each element into finished, escaped HTML, so search engines see it and a site needs no FlowCMS code to show it. Calculators come alive with one small script, `/api/public/elements.js`.
- One colour theme per workspace, set on Assets > Element templates (Edit theme): colours, corner radius and font (inherit the site's font or pick from a list). It is served as `/api/public/elements.css`, so a theme change needs no republish.
- Assets > Element templates shows a live preview of every template at phone, tablet and full width, with a sandbox to try the fields.
- Every element fits its container down to 280px wide: tables become cards on small screens and steps stack.

## Fixes and improvements

- The live preview editor leaves elements alone, so editing text on the page never damages one.
- General stability and performance improvements.
