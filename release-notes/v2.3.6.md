## Highlights

Elements now read correctly no matter which tool wrote the HTML.

## Fixes and improvements

- Elements written through the API or by an import script now display apostrophes, quotes and other special characters correctly. Before, element values written with hex or decimal HTML escapes (for example `&#x27;` for an apostrophe, the default in Python and many other libraries) showed the raw code on the page. FlowCMS now decodes every standard HTML escape in element data, so content saved by the Studio editor, the agent API or any script reads back exactly as written.
