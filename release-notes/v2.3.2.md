## Highlights

The Calculator element is now a calculator builder. Set up your own fields, options, extras and price range in the element drawer, with no code, and the published calculator works with the same maths the live preview uses.

## What's new

- Calculator builder (Enterprise, `elements`): number fields with a unit, a minimum, a maximum, a step, a starting value and a price per unit; choice fields shown as buttons or a dropdown; extras that are a flat amount or priced per unit of a number field.
- Every amount is a low and a high, so the result is always a range. Use the same number twice for a fixed price. A base amount and a minimum charge can be set for the whole calculator.
- Each option of a choice can add an amount, multiply the price, swap a number field's price per unit, set its own minimum, show a note, carry an est. mark, or switch the result to "Ask for a quote". Multipliers apply to the work, never to extras.
- Show only if: any field can appear only when a choice holds certain options, or when an extra is ticked. A field whose parent is hidden stays hidden.
- Optional plan: per visit and per year, with visits per year and an optional per-visit price for each plan option.
- Result settings: label, total or per visit, a yearly line, a "how this is worked out" breakdown, a note, a coverage line, and advice lines that appear when the result is over an amount.
- The drawer has a dedicated editor for all of this (add, reorder and remove fields; every option property; show-only-if pickers) and a live preview that recalculates as you edit, using the same calculation as the published page.
- The insert menu now adds a blank general calculator (one number, one choice, one extra, no amounts) ready to fill in.
- Cost estimator, Steps and Table now start with neutral sample content instead of example wording and prices.

- Element templates (Enterprise, `elements`): save any element as a named workspace template and insert it on as many pages as you like. Pages link to the template, so changing its values changes every page that uses it, with no republish; subscriber sites get the usual content update webhook for each published page. To give one page different numbers, duplicate the template under a new name and link that page to the copy. Deleting a template that is still in use asks first, and pages keep their last saved values. Templates can be renamed, exported and imported as JSON, and are included in workspace backups.

## Fixes and improvements

- Calculators made before this release (drying cost, insurance out of pocket and custom price x quantity) keep rendering exactly as before and can still be edited.
- The calculator script served at `/api/public/elements.js` now runs the same calculation as the page's first render, so the first paint and the live result cannot disagree.
- General stability and performance improvements.
