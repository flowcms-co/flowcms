# v1.7.8: bulk delete, duplicate and missing-alt filters

The Assets page could only delete one file at a time, which made
cleaning up a large library slow. Every card now has a checkbox. Tick
one and a selection bar appears with Select all, Clear and Delete, so
dozens of files can go in one step. While a selection is active,
clicking a card adds it to the selection instead of opening its
details.

## Duplicate uploads are flagged

Uploading a file that already exists in the workspace is now detected.
Both copies get a Duplicate badge, and after the upload finishes a
notice says how many files were duplicates, with a link to review them.
The file is still uploaded; you decide which copy to keep.

A new Duplicates filter shows every duplicated file in the library,
with the copies next to each other, so the extras can be selected and
deleted together.

## Missing alt filter

A new Missing alt filter lists every image in the library that has no
alt text yet. The "missing alt" count in the toolbar now opens this
filter too. Both filters cover the whole library, not only the files
already loaded on the page, and work together with search.

## Notes

One additive database migration (a content hash on media, used to spot
duplicates); it applies automatically on boot as always. Files uploaded
before this version have no hash, so duplicates among them are not
flagged. API and studio.
