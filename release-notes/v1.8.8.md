# v1.8.8: the studio's fonts ship with it

The studio used Google Fonts for Inter and Poppins, and downloaded them
while it was being built. When Google could not be reached from the
build machine, the build failed; that is what stopped the first image
build of v1.8.7.

Both fonts are now part of the repository, in the same latin subsets
Google served, and the studio loads them from its own files. Building
the studio makes no network request for fonts, and the studio looks
exactly as before. Inter and Poppins are licensed under the SIL Open
Font License.

## Notes

No migrations, no config changes, no new environment variables. Studio
only.
