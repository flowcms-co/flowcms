## Highlights

Your site can now preview a draft with just the link Studio gives it, with no extra API key or secret.

## What's new

- Preview drafts on your site: the delivery API accepts the signed preview token from a preview URL (`X-FlowCMS-Preview-Token` header, or `preview_token` query parameter) and returns that one entry even while it is a draft, shaped and expanded exactly like a published entry. Your site keeps its normal Content API token and no longer needs a Preview key or a copy of the preview secret.
- New `GET /api/public/preview/verify` tells your site whether a token is valid for a page, so it can switch on edit mode for published pages too.
- Responses that carry a preview token are never cached. List endpoints ignore preview tokens: one token opens one entry.
- Tighter live-edit messaging: the live-edit script and Studio preview now only exchange messages with each other's exact origin.
- See "Preview drafts on your site" under Developers > API Docs.

## Fixes and improvements

- General stability and performance improvements.
