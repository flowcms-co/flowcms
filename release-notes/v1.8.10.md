# v1.8.10: the Body editor appears only where the model has a body

The editor showed its large Body editor on any content type with a
rich text field, whatever that field was called, and wrote its content
into a body key on every save. A type with an "Intro text" field got a
Body editor it never asked for and a stray body value in its data,
while the Intro text field itself could not be edited at all: the form
hid every rich text field on the assumption that the Body editor
covered it.

The Body editor edits the entry's body, so it now appears only where
that is part of the model: a type with no fields of its own, a type
with a rich text field named body, or an entry that already holds body
text from before this change, so older content stays editable. Every
other rich text field is edited in place in the form, and a typed
model no longer gets a body written into its data.

To give a type the Body editor, add a rich text field named body. The
starter Page and Landing Page types now name their free-text field
Body for that reason. Existing types are not changed.
