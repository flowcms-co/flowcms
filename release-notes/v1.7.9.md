# v1.7.9: safer deletes, alt text that follows the image

Deleting an image that a page still uses now warns first. The Assets
page checks every page, including unpublished drafts, and lists the
ones that use the file before you confirm, so a cleanup can't quietly
leave broken images on the site. This works for single and bulk
deletes.

## Alt text comes from the asset library

When you pick a library image into an image field, its alt text field
is filled in from the asset's alt text. An alt field is matched to its
image when it is named after it ("Hero image alt"), or when it is the
only alt field next to the only image field, as in the built-in Image
component. Alt text you typed yourself is never overwritten; alt text
that was filled in automatically is updated if you swap the image.
Images inserted into rich text and the page body get the asset's alt
text too.

For pages that already exist, a new Fill page alt text button on the
Assets page copies asset alt text onto every page that uses a library
image without any. It runs in the background. Drafts are updated
directly; live pages get the change as a draft to approve and publish,
so nothing changes on the site until someone publishes it. Running it
again only touches pages that still need it.

## Content list

- Coming back from the editor returns to the list as you left it: the
  same search, filters, sort and page. These now live in the address
  bar, so reloading or sharing the link keeps them too.
- A new author filter sits next to the type filter.

## Assets page

- Files with the same name are now flagged as duplicates, as well as
  files with identical content. Names are compared ignoring case, and
  this also covers files uploaded before v1.7.8. The Duplicates view
  keeps matching names next to each other.
- The toolbar shows how many assets are in the library, or how many
  match when a search or filter is active.
- The search bar and selection bar stay pinned while you scroll.

## Notes

No migrations, no config changes, no new environment variables. API
and studio.
