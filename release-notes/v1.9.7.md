# v1.9.7: agent changes are named in version history

Versions and activity saved through the agent API before v1.9.6 had no
author stored, so version history showed "Unknown" and the activity log
"System".

- Such a change is now named after the API token that made it when only one
  Agent or Admin token existed at that moment, for example "City pages script
  (API token)". Otherwise it reads "API agent".
- An unattributed publish from before v1.9.6 reads "Scheduled publish or API
  agent", since scheduled publishes were logged the same way then.
- The dashboard's Recent activity uses the same names.

Changes since v1.9.6 already store the token's name. No migrations, no config
changes.
