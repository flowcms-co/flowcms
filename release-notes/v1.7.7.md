# v1.7.7: asset search finds everything

Searching the media library only looked through the most recent files
the page had loaded: the newest 500 on the Assets page, and the newest
100 in the image picker inside the editor. In a larger library, typing
the name of an older image came back empty even though the file was
there. Both search boxes now search the whole library on the server, so
any image can be found no matter when it was uploaded.

Search also matches alt text now, not only the file name, so an image
called IMG_4471.webp can be found by typing what is in the picture.

## Also fixed

- Picking a media result in the global search (Cmd+K) now opens the
  Assets page already filtered to that file. It used to open the full,
  unfiltered library.
- An asset search with no results now says so, instead of suggesting
  the library is empty.

## Notes

Studio only. No migrations, no config changes, no new environment
variables.
