## Highlights

Formatting rules for articles (Enterprise, `content_rules`): set what an article may contain, and anything that breaks the rules cannot be published, scheduled or approved, by anyone, including API and agent writes.

## What's new

- Content rules are an Enterprise feature, unlocked by the `content_rules` entitlement in the license. Without it every rule check is inert and nothing is ever blocked, tidied or flagged; stored rules stay in place and do nothing, so a lapsed license cannot stop publishing. Setting rules on a type, both tidy endpoints and the Content > Quality > Formatting list need the license; real-time auto tidy in the editor uses the same key.
- Settings > Content > Content rules: each content type with rules has its own guide link, shown as "See: label" next to rule messages (https only).
- Content rules: each content type can carry its own rules (which formatting a box allows, one list per section, no empty sections, an exact number of steps, and more). Saving a draft that breaks a rule always works and lists what is left to fix; publishing, scheduling and approving are refused until it is fixed.
- Plain messages: each problem says where it is (the field name as shown in the editor, plus the item number), what is wrong, and exactly what to do, with an optional guide link, set per content type in Settings.
- Fix before publishing: a list of everything that needs fixing, with a link on each item that jumps to it. Problems also show under their field as you work.
- A trimmed editor: a box that does not allow lists or headings no longer offers those buttons, and pasting from a document drops what the box does not allow.
- Auto tidy: extra spaces, stray hard spaces, empty paragraphs, trailing line breaks, runs of blank lines, pasted fonts and styles, and trailing colons on headings are cleaned as you type or paste, and again when saved. Words are never changed. A small note says what was tidied.
- Content > Quality has a new Formatting list that finds every draft or live page that could not be published as it is. Tidy fixes one page, and Tidy all flagged fixes them all: spaces, empty paragraphs, trailing colons and pasted styles, never a word. Each is saved as a draft, nothing is published, and it shows in the activity log.
- Ready-made rule sets for Resources and Service pages, including step wording, the closing help section, FAQ rows, links in bullet points, empty headings and city placeholders. Headings may end with a question mark; FAQ questions still need one.

## Fixes and improvements

- Saving a content type in the Schema Builder no longer drops its content rules.
- A scheduled page that no longer meets its rules goes back to draft instead of going live.
- Security: the studio now runs Next.js 16.4.6, the latest security patch.
- General stability and performance improvements.
